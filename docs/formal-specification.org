#+TITLE: CP-Net: 범주론적 전파자 네트워크 모델의 형식 명세서

* 1. 개요
본 문서는 CP-Net 계산 모델의 형식 명세를 정의함. CP-Net은 범주론적 구조를 가진 전파자 네트워크 기반 계산 모델로, 조건부 논리, 자료구조, 고차 함수, 재귀 등 복잡한 계산을 표현함. 모델의 구성요소, 공리, 튜링 완전성을 정의하고 예제로 증명함.

* 2. 모델의 형식적 정의
객체가 계산 셀(cell)이고 사상(morphism)이 전파자(propagator)인 범주(category)로 정의됨.

** 2.1 핵심 구성요소
*** 2.1.1 셀 (Cell)
*셀*: 저장소의 기본 단위이며, 범주 내 객체임.
- *ID*: 고유 ID를 가짐.
- *값(Value)*: 값을 보유함. 특별한 값 `#f`(false)는 비어 있거나 정의되지 않은 상태를 의미함.
- *병합 함수(Merge Function)*: 다중 값 쓰기 시 충돌 해결을 위한 함수를 가짐.

*** 2.1.2 전파자 (Propagator)
*전파자*: 소스 셀 값을 읽어 타겟 셀에 쓸 새 값을 제안하는 방향성 프로세스이며, 범주 내 사상임.
- *ID*: 고유 ID를 가짐.
- *연결*: 소스 셀(정의역)과 타겟 셀(공역)을 연결함.
- *함수*: 입력 값 기반으로 출력 값을 계산하는 함수를 포함함.

** 2.2 네트워크 (범주)
CP-Net: 셀과 전파자의 모음. 형식적으로 범주 C = (객체, 사상)으로 정의됨.
- *객체(Objects)*: 네트워크에 있는 모든 셀의 집합.
- *사상(Morphisms)*: 네트워크에 있는 모든 전파자의 집합.
- *합성(Composition)*: 전파자의 합성이 정의되어 있어, 계산을 연쇄적으로 연결할 수 있습니다.
- *항등(Identity)*: 각 셀에 대해 항등 전파자가 존재합니다.

** 2.3 실행 의미론 (Execution Semantics)
계산은 네트워크가 안정 상태(고정점)에 도달할 때까지 반복적 스텝핑으로 진행됨.
1. `runtime-settle!` 프로시저가 네트워크에 대해 호출됨.
2. 각 스텝(`_runtime-step!`)에서 모든 전파자가 실행됨.
3. 전파자는 소스 셀 값이 `#f`가 아닐 때 실행됨.
4. 각 셀에 대해 제안된 모든 새 값이 수집됨.
5. 한 셀이 다중 업데이트를 받으면, 셀의 병합 함수가 충돌을 해결함.
6. 어떤 셀의 값이라도 변경되면, 네트워크는 불안정 상태로 간주되어 다음 스텝이 실행됨.
7. 셀 값 변경 없이 한 스텝이 완료되면 프로세스는 종료됨. 이 프로세스는 Scheme 런타임의 꼬리 호출 최적화(TCO) 덕분에 스택 오버플로우를 유발하지 않음이 보장됨.

* 3. 계산 원시자 (공리)
모델의 표현력은 원시 전파자 생성자 집합(공리)에서 나옴. 이들은 계산 시스템의 기초를 형성함.

** 3.1 기초 원시자
- `p-const`: 상수 값을 씁니다.
- `p-gate`: 조건부 데이터 흐름 (IF-THEN-ELSE).
- `p-equal?`: (새로운 공리) 두 셀 간의 동등성을 확인합니다.

** 3.2 자료구조 원시자
- `p-cons`: 쌍 `(pair h t)`을 구성합니다.
- `p-car`: 쌍의 첫 번째 요소를 추출합니다.
- `p-cdr`: 쌍의 두 번째 요소를 추출합니다.

** 3.3 산술 원시자
- `p-is-zero`: 값이 0인지 확인합니다.
- `p-subtract-1`: 값을 1 감소시킵니다.
- `p-multiply`: 두 값을 곱합니다.

** 3.4 고차 및 재귀 원시자
- `p-apply`: 함수(셀의 쌍으로 표현됨)를 인자에 적용합니다.
- `make-fixpoint-net`: 일반적인 재귀 계산을 구성하기 위한 네트워크 생성자 (고정점 조합기, fixed-point combinator).

* 4. 계산 가능성 (Computability)
CP-Net 모델은 **튜링 완전(Turing-complete)**함.

제공된 원시자들은 튜링 기계 시뮬레이션 또는 일반 재귀 함수 정의에 충분하므로 위 주장은 정당함.
- *데이터 표현*: `p-cons`, `p-car`, `p-cdr`로 리스트(튜링 기계 테이프) 구성 가능함.
- *조건부 분기*: `p-gate`는 상태 전이에 필요한 `IF-THEN-ELSE` 논리를 제공함.
- *무한 루프*: `make-fixpoint-net`은 일반 재귀(무한 루프)를 제공함.
- *기본 연산*: 산술 및 동등성 원시자는 기호 조작 및 종료 조건 확인을 가능하게 함.

따라서, 모든 계산 가능한 알고리즘은 CP-Net 내에서 모델링 가능함.

* 5. 계산 예제

** 5.1 예제: 조건문 (IF TRUE 100 200)
#+BEGIN_SRC scheme
(use-modules (cpnet core)
             (cpnet runtime)
             (cpnet category)
             (cpnet lambda))

(define trigger (make-cell 'trigger #f))
(define control (make-cell 'control #f))
(define then-val (make-cell 'then-val 100))
(define else-val (make-cell 'else-val 200))
(define result (make-cell 'result #f))

(define p-true (p-const 'TRUE trigger control 'true))
(define p-if (p-gate 'IF control then-val else-val result))

(define C (make-cpnet-category
           (list trigger control then-val else-val result)
           p-if))

(category-add-morphism C p-true)
(cell-set-value! trigger #t)
(runtime-settle! C)
(format #t "IF TRUE 100 200 -> ~a\n" (cell-value result))
#+END_SRC

** 5.2 예제: 자료구조 - list(1, 2)
#+BEGIN_SRC scheme
(use-modules (cpnet core)
             (cpnet runtime)
             (cpnet category)
             (cpnet lambda))

(define c1 (make-cell 'c1 1))
(define c2 (make-cell 'c2 2))
(define c-nil (make-cell 'nil 'nil))
(define list-part (make-cell 'list-part #f))
(define full-list (make-cell 'full-list #f))
(define car-result (make-cell 'car-result #f))

(define build-props (append (p-cons 'cons1 c2 c-nil list-part)
                            (p-cons 'cons2 c1 list-part full-list)))
(define decon-props (list (p-car 'car-op full-list car-result)))
(define C (make-cpnet-category
           (list c1 c2 c-nil list-part full-list car-result)
           (append build-props decon-props)))

(runtime-settle! C)
(format #t "Constructed List: ~a\n" (cell-value full-list))
(format #t "car(list) -> ~a\n" (cell-value car-result))
#+END_SRC

** 5.3 예제: 고차 함수 - (apply ID 555)
#+BEGIN_SRC scheme
(use-modules (cpnet core)
             (cpnet runtime)
             (cpnet category)
             (cpnet lambda))

(define id-input (make-cell 'id-input #f))
(define id-output (make-cell 'id-output #f))
(define p-id (make-propagator 'p-id id-input id-output (lambda (v _) (cons v '()))))
(define ID-Net (make-cpnet-category (list id-input id-output) (list p-id)))
(define id-func-representation (list 'pair id-input id-output))

(define func-holder (make-cell 'func-holder #f))
(define arg (make-cell 'arg 555))
(define result (make-cell 'result #f))
(define p-app (p-apply 'app func-holder arg result))

(define Main-Net
  (make-cpnet-category
   (append (list func-holder arg result) (category-objects ID-Net))
   (append (list p-app) (category-morphisms ID-Net))))

(cell-set-value! func-holder id-func-representation)
(runtime-settle! Main-Net)
(format #t "Apply(ID, 555) -> ~a\n" (cell-value result))
#+END_SRC

** 5.4 예제: 재귀 - factorial(5)
#+BEGIN_SRC scheme
(use-modules (cpnet core)
             (cpnet runtime)
             (cpnet category)
             (cpnet lambda))

(define n         (make-cell 'n       #f))
(define acc       (make-cell 'acc     1))
(define n-next    (make-cell 'n-next  #f))
(define acc-next  (make-cell 'acc-next #f))
(define is-zero   (make-cell 'is-zero #f))
(define result    (make-cell 'result  #f))

(define p-decr    (p-subtract-1 'decr-n n n-next))
(define p-mult    (p-multiply   'mult-acc n acc acc-next))
(define p-test    (p-is-zero 'is-zero n is-zero))

(define FACT-Net
  (make-fixpoint-net
   (list acc n)
   (list acc-next n-next)
   (cons p-decr p-mult)
   p-test
   is-zero
   (list result)))

(cell-set-value! acc 1)
(cell-set-value! n 5)
(runtime-settle! FACT-Net)
(display (format #f "5! = ~a\n" (cell-value result)))
#+END_SRC

** 5.5 예제: 동등성 공리 - (equal? 5 5)
새로운 `p-equal?` 원시자 사용법.
#+BEGIN_SRC scheme
(use-modules (cpnet core)
             (cpnet runtime)
             (cpnet category)
             (cpnet lambda))

(define a (make-cell 'a 5))
(define b (make-cell 'b 5))

* 6. 형식적 의미론 (Formal Semantics)
본 섹션은 전제-판단(premise-judgment) 스타일의 추론 규칙을 사용해 모델의 연산 의미론을 형식적으로 정의함. 이 규칙들은 네트워크 상태 변화를 정확히 기술함.

** 6.1 표기법 (Notation)
- *상태 (State)* `σ`: 셀 ID에서 값으로의 매핑 `(ID → Value)`. `σ(c)`는 셀 `c`의 현재 값을 나타냄.
- *네트워크 (Network)* `C`: 셀과 전파자로 구성된 CP-Net 범주.
- *단일 스텝 평가 (Single-Step Evaluation)* `C; σ ⟶ σ'`: 네트워크 `C`의 단일 전파 스텝 실행으로 상태 `σ`가 `σ'`로 바뀜을 의미함 (`_runtime-step!` 해당).
- *전체 평가 (Full Evaluation)* `C; σ ⇓ σ'`: 네트워크 `C`가 상태 `σ`에서 안정 상태 `σ'`에 도달함을 의미함 (`runtime-settle!` 해당).

** 6.2 추론 규칙 (Inference Rules)
추론 규칙은 `Premise / Conclusion (Rule-Name)` 형식으로 표현됨.

*** 6.2.1 실행 규칙
네트워크의 전체 실행 흐름을 제어함.

#+BEGIN_EXAMPLE
 C; σ ⟶ σ'     σ' ≠ σ
------------------------ (STEP)
    C; σ ⇓ σ''
  if C; σ' ⇓ σ''
#+END_EXAMPLE

#+BEGIN_EXAMPLE
  C; σ ⟶ σ
-------------- (DONE)
   C; σ ⇓ σ
#+END_EXAMPLE

이 규칙들은 `runtime-settle!`이 고정점에 도달할 때까지 `_runtime-step!`을 반복 호출하는 과정을 모델링함.

*** 6.2.2 원시 전파자 규칙
개별 원시 전파자의 동작을 정의함. `p ∈ C`는 전파자 `p`가 네트워크 `C`의 멤버임을 의미함.

*Gate (조건부)*
#+BEGIN_EXAMPLE
p-gate(id, c, t, f, o) ∈ C   σ(c) = 'true   σ(t) = v
------------------------------------------------------ (GATE-T)
            C; σ ⟶ σ'  where σ'(o) = v

p-gate(id, c, t, f, o) ∈ C   σ(c) = 'false   σ(f) = v
------------------------------------------------------- (GATE-F)
            C; σ ⟶ σ'  where σ'(o) = v
#+END_EXAMPLE

*Equal? (동등성 비교)*
#+BEGIN_EXAMPLE
p-equal?(id, a, b, o) ∈ C   σ(a) = v_a   σ(b) = v_b
---------------------------------------------------------- (EQUAL)
 C; σ ⟶ σ' where σ'(o) = (if (equal? v_a v_b) 'true 'false)
#+END_EXAMPLE

*Multiply (곱셈)*
#+BEGIN_EXAMPLE
p-multiply(id, a, b, o) ∈ C   σ(a) = v_a   σ(b) = v_b
---------------------------------------------------------- (MULT)
       C; σ ⟶ σ'  where σ'(o) = v_a * v_b
#+END_EXAMPLE

*Cons (쌍 구성)*
#+BEGIN_EXAMPLE
p-cons(id, h, t, o) ∈ C   σ(h) = v_h   σ(t) = v_t
---------------------------------------------------------- (CONS)
   C; σ ⟶ σ'  where σ'(o) = (list 'pair v_h v_t)
#+END_EXAMPLE

*Car/Cdr (쌍 분해)*
#+BEGIN_EXAMPLE
p-car(id, p, o) ∈ C   σ(p) = (list 'pair v_h v_t)
---------------------------------------------------- (CAR)
           C; σ ⟶ σ'  where σ'(o) = v_h

p-cdr(id, p, o) ∈ C   σ(p) = (list 'pair v_h v_t)
---------------------------------------------------- (CDR)
           C; σ ⟶ σ'  where σ'(o) = v_t
#+END_EXAMPLE

이 형식적 규칙들은 CP-Net 모델의 계산 동작에 대한 명확하고 모호하지 않은 기초를 제공하며, 정확성 증명 및 추가 시스템 분석을 가능하게 함.

* 7. 형식적 증명: `runtime-settle!`의 수렴성
본 섹션은 `connect` 효과로 인해 네트워크가 동적으로 변하는 경우까지 포함하여, CP-Net의 핵심 실행 모델 `runtime-settle!`이 항상 유일한 최소 고정점(least fixed point)으로 수렴함을 형식적으로 증명함.

**7.1 증명 개요**
1.  *확장된 상태 공간*: 시스템의 전체 상태를 네트워크 구조(범주 `C`)와 셀 값(매핑 `σ`)의 쌍 `(C, σ)`으로 정의하고, 이 상태 공간 위에 완비 부분 순서(CPO)를 정의함.
2.  *동적 상태 변환*: `runtime-settle!`의 한 루프를 확장된 상태 공간 위의 자기함수 `T_dyn`으로 모델링함.
3.  *연속성 증명*: `T_dyn`이 스콧 연속(Scott-continuous) 함수임을 증명함.
4.  *고정점 정리 적용*: **클레이니 고정점 정리**를 적용하여, `runtime-settle!`이 `T_dyn`의 최소 고정점을 올바르게 계산함을 보임.

**7.2 1단계: 확장된 상태 공간 `S`의 정의**
- *시스템 상태*: 시스템의 한 시점 상태는 쌍 `(C, σ)`로 정의됨.
  - `C`: 네트워크의 구조(객체와 사상)를 나타내는 범주.
  - `σ`: 각 셀의 값을 나타내는 매핑 `σ: Ob(C) → V`.
- *상태 공간의 순서*: 두 상태 `s₁ = (C₁, σ₁)`와 `s₂ = (C₂, σ₂)`에 대해, 정보 순서 `⊑_S`를 다음과 같이 정의함:
  `s₁ ⊑_S s₂` iff (`C₁`는 `C₂`의 부분범주) ∧ (`σ₁ ⊑ σ₂`).
  - `C₁ ⊆ C₂`는 `Ob(C₁) ⊆ Ob(C₂)` 이고 `Mor(C₁) ⊆ Mor(C₂)` 임을 의미.
  - `σ₁ ⊑ σ₂`는 `C₁`의 모든 셀 `c`에 대해 `σ₁(c) ≤ σ₂(c)`가 성립함을 의미.
- *결론*: `(S, ⊑_S)`는 최소 원소 `s_⊥ = (C_init, σ_⊥)`를 갖는 완비 부분 순서(CPO)를 형성함.

**7.3 2단계: 동적 상태 변환 함수 `T_dyn` 정의**
`runtime-settle!`의 한 루프는 `T_dyn: S → S` 함수로 모델링됨. `T_dyn((C, σ)) = (C', σ')`는 다음 과정으로 정의됨:
1.  *값 전파*: `_runtime_step!`의 값 전파 로직을 함수 `T_val(C, σ) = σ_next`로 간주함. `σ_next(c)`는 `σ` 상태의 `C` 네트워크에서 `c`로 전파된 값들의 병합 결과임. 만약 `c`로 전파된 값이 없으면 `σ_next(c) = σ(c)`임.
2.  *효과 수집*: 값 전파 과정에서 발생한 모든 효과(effect) 목록 `E`를 수집함.
3.  *네트워크 확장*: `connect` 효과를 처리하여 `C`를 확장한 새로운 범주 `C'`를 생성함. `C' = C ∪ {p | p는 connect 효과로 생성된 전파자}`.
4.  *값 변경*: `set-value` 등 나머지 효과를 `σ_next`에 적용하여 최종 값 상태 `σ'`를 생성함.

**7.4 3단계: `T_dyn`의 스콧 연속성 증명**
- *단조성*: `s₁ ⊑_S s₂` 이면 `T_dyn(s₁) ⊑_S T_dyn(s₂)`임을 증명해야 함.
  1. *구조*: `C₁ ⊆ C₂`이므로 `T_dyn(s₁)`에서 생성된 `C'₁`는 `T_dyn(s₂)`에서 생성된 `C'₂`의 부분범주임 (`C'₁ ⊆ C'₂`).
  2. *값*: `σ₁ ⊑ σ₂`이므로, `T_val`의 단조성에 의해 `T_val(C₁, σ₁) ⊑ T_val(C₂, σ₂)`임. 효과 처리 역시 단조성을 유지함. 따라서 최종적으로 `σ'₁ ⊑ σ'₂`임.
  3. *결론*: `(C'₁, σ'₁) ⊑_S (C'₂, σ'₂)`이므로, `T_dyn`은 단조적임.
- *연속성*: `T_dyn`의 각 구성요소(값 전파, 효과 처리)는 이전 상태 값에 직접 의존하지 않고 오직 입력 셀들의 값에만 의존함 (`default-merge-fn`이 충돌 시 `⊥`을 반환하는 조건 덕분). 따라서 `T_dyn`은 연속적인 함수들의 합성으로 이루어져 스콧 연속성을 만족함.

**7.5 4단계: 클레이니 고정점 정리 적용**
- *정리*: `(S, ⊑_S)`는 CPO이고 `T_dyn`은 스콧 연속 함수이므로, `T_dyn`은 유일한 최소 고정점 `s_fp = (C_fp, σ_fp)`를 가짐.
- *계산*: `runtime-settle!`은 초기 상태 `s_init`에서 시작하여 `s_init, T_dyn(s_init), T_dyn²(s_init), ...` 수열을 계산하며, 이는 최소 고정점으로 수렴함. 네트워크의 셀, 사상, 값의 종류가 유한한 경우, 이 사슬은 유한한 단계 내에 고정점에 도달하여 계산이 반드시 종료됨.

**7.6 결론**
1.  `runtime-settle!`의 계산 과정은 네트워크 구조가 동적으로 변하는 경우까지 포함하여, 확장된 상태 공간 CPO 위의 스콧 연속 자기함수 `T_dyn`의 최소 고정점을 찾는 과정과 수학적으로 동일함.
2.  클레이니 고정점 정리에 의해, 이 최소 고정점은 항상 유일하게 존재하며, 반복적인 계산을 통해 반드시 도달 가능함이 보장됨.
3.  이는 CP-Net 계산 모델이 구현 언어와 무관하게 항상 결정론적이고 안정적인 결과를 보장하는 엄밀한 수학적 토대를 가짐을 증명함.

**7.7 이벤트 기반 전파자 패턴 (Event-Based Propagator Pattern)**
본 시스템의 많은 부분(특히 `cpnet/detail.scm`)은 "이벤트 기반 전파자"라는 특정 디자인 패턴을 사용함. 이 패턴의 형식적 속성을 명시하는 것은 전체 모델의 완전성을 위해 중요함.

- *정의*: 이벤트 전파자 `p: A → B`는 입력 셀 `A`의 값이 `⊥`이 아닐 때 단 한 번만 실행되도록 설계된 전파자임.
- *형식적 동작*: 이 전파자는 사용자 함수 `f`를 실행하여 `B` 셀의 값을 계산하는 것 외에, 자신의 실행을 촉발한 입력 셀 `A`의 값을 다시 `⊥`로 설정하는 `(make-effect 'set-value (cons A ⊥))` 효과를 반드시 생성함.
- *수학적 의미*: 상태 변환 함수 `T_dyn` 내에서, 이벤트 전파자의 실행은 `σ'(A) = ⊥`를 보장함. 이 "자기-초기화" 메커니즘은 동일한 이벤트가 다음 `runtime-settle!` 루프에서 다시 처리되는 것을 막아, 시스템이 안정적으로 다음 상태로 진행하도록 보장함.
